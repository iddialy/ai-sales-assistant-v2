# AI Sales Assistant Tanzania — v6 (Payments Disabled)

Temporary test version. Signup, Login, PostgreSQL, product catalog and AI chat are enabled. Payment/MalipoPay is intentionally removed from the user flow so the core system can be tested first.

## Render environment
- DATABASE_URL
- JWT_SECRET
- GEMINI_API_KEY
- GEMINI_MODEL (optional)
- CORS_ORIGINS=https://iddialy.github.io
- FRONTEND_URL=https://iddialy.github.io/ai-sales-assistant-v2/

Do not put mobile-money PINs or secrets in the frontend.
